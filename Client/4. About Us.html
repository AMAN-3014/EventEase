We make events easy to find and easy to join

EventEase started as a small project to put a city's events in one clean place. Visitors see what is on and register quickly. Organizers keep their listings and sign-ups in order.

This site is a front-end learning project built with HTML, CSS and JavaScript, with wireframes first designed in Figma or Canva.
